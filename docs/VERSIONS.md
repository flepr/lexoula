# Λεξούλα — historique des versions

Numéro affiché dans Réglages › À propos, lu dans `package.json`. Même logique que MuscleMap :
**majeure** (x.0.0), **mineure** (1.x.0 : nouvelle fonction visible), **correctif** (1.8.x : correction).
Claude incrémente seul le correctif ; il demande l'accord de Fabien avant une mineure ou une majeure.
Une version = une livraison (une session de travail), pas un commit.

Les versions jusqu'à 1.8.1 ont été reconstituées le 11/11/2026 à partir de l'historique du dépôt
(1.0.0 = première version servie sur `app.lexoula.gr`, annoncée à la classe le 29/10/2026).
Avant : versions de test 0.x sur `flepr.github.io/lexoula/` (en ligne depuis le 23/10/2026).
